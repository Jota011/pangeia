Trabalho de UI e UX.

O objetivo deste projeto foi desenvolver uma página web para uma empresa fictícia de viagens, aplicando os principais 
princípios e métodos de UI (Interface do Usuário) e UX (Experiência do Usuário). A proposta foi criar uma interface visualmente
atrativa, intuitiva e funcional, capaz de proporcionar uma navegação fluida e agradável ao usuário. Durante o processo de 
desenvolvimento, foram considerados aspectos como hierarquia visual, escolha de cores, tipografia, usabilidade e responsividade.
